# image-to-vector

Локальный векторизатор растра в SVG: PNG/JPG → чистый SVG, полностью в браузере,
без загрузки файлов на сервер.

Ядро трассировки — [VTracer](https://github.com/visioncortex/vtracer) (MIT/Apache-2.0).
Своё — пре/постобработка, пресеты, живое сравнение с оригиналом, батч и CLI.

**Статус:** проектирование. Техническое задание — [`docs/SPEC.md`](docs/SPEC.md).
